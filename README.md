# Bridging Network Telemetry and GenAI

Slide deck for my 2026 ElasticON talk.

## Viewing the slides

- **GitHub Pages (interactive):** https://penguin02007.github.io/2026-elasticon-network-telemetry-genai/#1
  - Use the arrow keys, the on-screen buttons, or click the left or right side of a slide to move between slides. Press `f` for fullscreen.
  - Add `#<n>` to the URL to link to slide *n*.
- **PDF on GitHub:** [deck.pdf](https://github.com/penguin02007/2026-elasticon-network-telemetry-genai/blob/main/deck.pdf)

## Contents

- `index.html`: the slide viewer that GitHub Pages serves
- `slides/`: one image per slide
- `deck.pdf`: the full deck as a PDF
